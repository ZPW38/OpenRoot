## 新增第四个漏洞 CVE-2026-64560（posix-cpu-timers UAF）

- 上游原始代码：`C:\Users\Administrator\Downloads\opace6-cve-2026-64560`（OnePlus Ace 6 移植，
  5800 行 C，`--preflight` / `--run`），分析仓库 `C:\Users\Administrator\Downloads\CVE-2026-64560-Analysis`。
- 新目录 `native-pct/`（`opace6/exploit-fanout-opace6.c` + `NOTICE`），产物 `libpct-opace6.so`
  （NDK r27d，API 24，PIE，95KB）。Makefile 与其他引擎同构。
- 唯一本地改动：root 子进程支持 `OPENROOT_HANDOFF`，拿到 root 后 exec 暂存的 `loader`
  （`native-or/bootstrap.c`），而不是停在交互 shell —— 这样与 GPU / page cache 引擎共用同一套
  ksud late-load / root 命令通道（`/dev/dfm6` / `/dev/dfm1`）。
- `PctRunner.kt`：`Payload` 枚举自带 `matches(info)`（codename + fingerprint 前缀），
  `payloadFor(info)` 自动选 build；先 `--preflight`（指纹不符返回 `buildMismatch`，不写 ExploitMemory），
  再 `OPENROOT_HANDOFF=…/loader ./libpct --run`，进度按 `RACE_STAGE_BEGIN / STAGE0_GATE_PASS /
  MISC_BRIDGE_OPEN_PASS / PHYS_*_PASS / STAGE8_CRED_STAGE_PASS / ROOT_CHILD_HOLD_PASS` 推进。
- `DeviceInfo` 增加 `codename`（ro.product.device）与 `fingerprint`（ro.build.fingerprint），
  追加在 QUERIES 末尾以免打乱既有下标。
- Gradle：`buildNativePct` → `prepareNativePayloads`（唯一写 jniLibs）→ `stripNativePayloads`。
- 文档：`docs/CVE-2026-64560.md`（根因/竞态时序/修复/移植/驱动方式），README 与 THIRD_PARTY_NOTICES 同步。
